# Security

Glaze is a set of React components, a stylesheet and a static site. It runs no server and stores nothing. The realistic risks are a component that renders untrusted content unsafely (for example the Markdown renderer) or a registry item that installs something it should not.

## Reporting a vulnerability

Report it privately through [GitHub's security advisories](https://github.com/sumitttt4/glazeui/security/advisories/new), not in a public issue. Include the component or registry item, and steps to reproduce. You will get a reply within a few days.
