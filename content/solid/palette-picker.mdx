## Palette data

This component includes a required tailwind-palette.ts data file, derived from the installed Tailwind CSS tokens and converted to rounded sRGB hex. The registry installs both files. In the collection Source view, expand Required Tailwind palette data when copying manually. Shade buttons support arrow keys and Home/End; custom hex values need six digits.
