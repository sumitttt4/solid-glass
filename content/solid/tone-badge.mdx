---
title: Tone Badge
description: Label a category with a named color role and a paired foreground.
---

## Usage

```tsx
import { ToneBadge } from "@/components/ui/tone-badge"
<ToneBadge tone="fern">Design</ToneBadge>
```

Available tones: iris, fern, clay, sun, ocean. A badge always needs text; color alone is not a status label.
