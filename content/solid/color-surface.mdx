## Usage

```tsx
import { ColorSurface } from "@/components/ui/color-surface"
<ColorSurface tone="sun" aria-label="Project summary">Your content</ColorSurface>
```

Use tone-badge's ColorTone values. Import colorwork.css after the app's Tailwind/shadcn styles. Nested primary controls inherit the tone's solid action color.
