Glaze is designed and built by [Sumit Sharma](https://sumitsharma.pro). It is free and MIT licensed, and it stands on open-source work that deserves to be named.

## Foundations

- **[shadcn/ui](https://github.com/shadcn-ui/ui)** (MIT): the component patterns, the registry format and the command line that installs Glaze.
- **[Base UI](https://github.com/mui/base-ui)** (MIT): the accessible, unstyled primitives under the components.
- **[Solid Glass](https://github.com/deeplethe/solid-glass)** by DeepLethe (MIT): the glass stylesheet Glaze's materials grew from.
- **[Tailwind CSS](https://github.com/tailwindlabs/tailwindcss)** (MIT): the styling engine.

## Icons, type and backdrops

- **[Hugeicons](https://github.com/hugeicons)** (MIT): the icon set the animated icons are built on.
- **[Lucide](https://github.com/lucide-icons/lucide)** (ISC): icons in the inherited components and blocks.
- **[Manrope](https://github.com/sharanda/manrope)** by Mikhail Sharanda (OFL) and **[Geist Mono](https://github.com/vercel/geist-font)** (OFL): the typefaces.
- **[Paper Shaders](https://github.com/paper-design/shaders)** (Apache-2.0): the mesh gradients behind the site's glass previews.

## Components inside components

- [Recharts](https://github.com/recharts/recharts) for charts, [Embla Carousel](https://github.com/davidjerleke/embla-carousel) for the carousel, [Sonner](https://github.com/emilkowalski/sonner) for toasts and [cmdk](https://github.com/pacocoursey/cmdk) for the command menu.
- [React DayPicker](https://github.com/gpbl/react-day-picker) for the calendar, [input-otp](https://github.com/guilhermerodz/input-otp) for one-time codes, [TanStack Table](https://github.com/TanStack/table) for data tables, [dnd kit](https://github.com/clauderic/dnd-kit) for drag and drop and [react-resizable-panels](https://github.com/bvaughn/react-resizable-panels) for resizable layouts.
- [react-markdown](https://github.com/remarkjs/react-markdown) and [highlight.js](https://github.com/highlightjs/highlight.js) for rendered Markdown and code.

## Motion

The motion follows the design-engineering principles [Emil Kowalski](https://emilkowal.ski) teaches: fast, origin-aware popovers, custom easing and no animation where speed matters more.

## Licenses

Glaze keeps every original license notice. `LICENSE` holds the MIT notices for Glaze and Solid Glass, and `NOTICE.md` holds shadcn/ui's. If you copy Glaze's source into your own project, keep those notices with it.
