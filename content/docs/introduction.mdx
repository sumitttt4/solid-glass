Glaze is a free, open-source React component library by Sumit Sharma. It covers everyday interface components, AI and voice components, and animated icons, all designed together and each available in four finishes, from solid to glass. It is built on Solid Glass, shadcn/ui and Base UI, so every component is plain source you own.

## What's in it

- **Components:** buttons, forms, overlays, menus, data and navigation, restyled with one color system and one typeface.
- **AI and voice:** a chat window, model picker, token counter, prompt suggestions, live transcription, voice input, a voice orb, streaming text and text to speech.
- **Animated icons:** a dashboard set and an everyday set built on Hugeicons, plus `AnimatedIcon`, which animates any Hugeicon.
- **Blocks:** whole screens such as dashboards, sign-in pages and an agent workspace.

## How to use it

Browse [all components](/components). Every component has a live preview you can switch between finishes, the full source, and an install command. Add one with:

```bash
npx shadcn@latest add sumitttt4/solid-glass/chat-window#main
```

Start with [Installation](/docs/installation) to add the theme once.

## Your code, your call

Examples use made-up data and run in the browser: they don't send email, store anything or call a model. Connect your own data and handlers, and check contrast and behavior in your product before shipping.
