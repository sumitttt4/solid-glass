## Requirements

React 19, Tailwind CSS 4 and Base UI. Type is Manrope throughout (`npm i @fontsource-variable/manrope`). The components follow shadcn/ui's file layout (`@/components/ui`, `@/lib/utils`), so a project set up with `npx shadcn@latest init` is ready.

## 1. Add the theme

```bash
npx shadcn@latest add sumitttt4/glazeui/glaze#main
```

This copies three stylesheets: `glaze.css` (colors, type, controls), `materials.css` (Glass, Frost and Aurora) and `solid-glass.css` (the foundation both build on). Import them after Tailwind:

```css
@import "tailwindcss";
@import "tw-animate-css";
@import "shadcn/tailwind.css";
@import "@fontsource-variable/manrope";
@import "@fontsource-variable/geist-mono";
@import "./glaze.css";
@import "./materials.css";
```

## 2. Add components

Any component, by name. Its dependencies come with it.

```bash
npx shadcn@latest add sumitttt4/glazeui/chat-window#main
npx shadcn@latest add sumitttt4/glazeui/animated-icons#main
npx shadcn@latest add sumitttt4/glazeui/button#main
```

Every component page at /components has an Install tab with its command and a Code tab with the full source, if you would rather copy it.

## 3. Choose a material

Set `data-material` on `<html>` for the whole app, or on any element to finish just that part:

```html
<html data-material="solid">   <!-- Normal: opaque -->
<html data-material="glass">   <!-- Glass: thick, smoky glass -->
<html data-material="frost">   <!-- Frost: clear glass over vivid light -->
<html data-material="aurora">  <!-- Aurora: frost over light that moves -->
```

Glass needs something behind it to read as glass. The page draws soft light of its own, and the `mat-stage` class gives any box the same backdrop. `MaterialPicker` is a ready-made switch.

## Use with a coding agent

Agents can install Glaze on their own. Pick whichever fits your agent:

- **Agent skill:** `npx skills add sumitttt4/glazeui` installs the Glaze skill, which tells the agent how to add the theme, pick components and set finishes. In Claude Code you can also copy [`skills/glaze`](https://github.com/sumitttt4/glazeui/tree/main/skills/glaze) into `.claude/skills/`.
- **llms.txt:** point the agent at [glazeui.xyz/llms.txt](/llms.txt), a plain-text list of every component with its install command.
- **A prompt:** paste this into any agent:

```text
Use Glaze (github.com/sumitttt4/glazeui) for UI. The component list is at https://glazeui.xyz/llms.txt.
Add the theme once: npx shadcn@latest add sumitttt4/glazeui/glaze#main
Add components with: npx shadcn@latest add sumitttt4/glazeui/<name>#main
Use data-material="glass" on <html> for the glass finish.
```

## Run this site locally

```bash
git clone https://github.com/sumitttt4/glazeui.git
cd glazeui
npm ci
npm run dev
```

Use Node 22.12+. Open http://localhost:5191.
